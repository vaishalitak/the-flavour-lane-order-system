## Project Overview

The Flavour Lane is a cloud kitchen website with a customized WooCommerce order management system designed to handle online orders, in-store orders, and walk-in orders from a centralized dashboard.

The project includes custom ordering workflows, inventory automation, administrative tools, and customer communication features.

## Key Features

### 1. Custom Order Management Dashboard
- Centralized order management interface
- Separate order source filters
- Website, store and walk-in order management
- Order status tracking
- New order notification functionality

### 2. QR-Based Ordering
- QR code ordering workflow for in-store customers
- Integration with WooCommerce orders
- Centralized order processing

### 3. Inventory & Stock Management
- Unified stock tracking across order sources
- Automated stock adjustments
- Stock availability monitoring
- Product quantity management

### 4. Custom Billing System
- Daily bill numbering
- Invoice generation and printing
- Custom walk-in order entry
- Order amount and quantity adjustments

### 5. WhatsApp Notifications
- Order confirmation notifications
- Order processing updates
- Order completion notifications
- Integration with customer communication workflows

### 6. WooCommerce Customization
- Custom PHP functionality
- WooCommerce hooks and filters
- AJAX-based administrative features
- Custom dashboard interface
- Order management improvements
